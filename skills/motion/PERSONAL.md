## Local scope: free Motion AI Kit

Use `best-practices/` for animation guidance and `search-motion-docs` on the
`motion` MCP server for documentation and example discovery. Read relevant
documentation resource links returned by the server before implementing.

This installation uses only https://mcp.motion.dev, without an account or API
key. The MCP server's discovered tools are authoritative: upstream references
to easing generation do not mean that tool is available here.

Motion+ is not purchased or configured. Treat the upstream audit, transition
editor and premium-source instructions as out of scope. Use free documentation,
free example source when provided, and public demo links. Do not add the
Motion+ server, start a sign-in or purchase flow, or install `motion-plus`.

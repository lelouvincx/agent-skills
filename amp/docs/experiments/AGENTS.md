# Amp experiment documentation rules

- Before creating or editing an experiment doc, read `_schema.md`; it is the sole contract for frontmatter, headings, identifiers and filenames.
- Load `clear-writing` before writing experiment prose.
- Append observations to the `Observation log` and update `updated`. Keep earlier rows as written.
- Link every experiment from `README.md`, and keep its status there in step with the frontmatter.

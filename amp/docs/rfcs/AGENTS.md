# RFC documentation rules

- Before creating or editing an RFC, read `_rfc_schema.md`; it is the sole contract for frontmatter, headings, relationships, and the new-RFC template.
- For older RFCs, follow the migration policy in `_rfc_schema.md`; do not rewrite unrelated historical content solely for formatting.
- Keep relationship paths relative to this directory.
- Do not create alternate RFC schema or template files; update `_rfc_schema.md`.
